# HabitTracker

A local-first native Android habit tracker focused on daily Islamic habits and personal routines.

HabitTracker provides a calm daily checklist for the five Salat, Quran, morning and evening Adhkar, Sadaqah, and user-created personal habits. It also includes date-based history, monthly progress, current streaks, and Light, Dark, and System themes.

## Features

- Daily Salat tracking
- Quran, Adhkar, and Sadaqah tracking
- Custom personal habits
- Read-only date-based history
- Monthly completion progress
- Per-habit current streaks
- Light, Dark, and System themes
- Fully offline, on-device storage

## Privacy

HabitTracker has no backend, requires no account, and has no cloud dependency. Habit and completion data remains on the user's Android device.

## Tech stack

- Kotlin
- Jetpack Compose
- Material 3
- Room
- DataStore
- Navigation Compose
- ViewModel and Flow

## Build

Open the project in Android Studio or build a debug APK from the project root:

```powershell
.\gradlew.bat assembleDebug
```

The resulting debug APK is generated under `app/build/outputs/apk/debug/` and should not be committed to Git.
